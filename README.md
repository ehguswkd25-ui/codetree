# 코드트리 문제 풀이

[코드트리](https://www.codetree.ai/)에서 푼 문제를 GitHub 연동으로 자동 기록하는 저장소입니다.
문제를 정답 처리하면 풀이 코드와 문제 설명이 커리큘럼(Trail) 단위로 자동 커밋됩니다.

## 사용 언어

- Python 3

## 저장소 구조

```
<trail 이름>/
└─ <문제 이름>/
   ├─ <문제-slug>.py   # 제출한 풀이 코드
   └─ README.md        # 문제 설명 · 난이도 · 커리큘럼 링크 (코드트리 자동 생성)
```

- 커밋 메시지: `[Passed] <문제 이름> (실행시간, 메모리)` — 코드트리 봇이 자동 생성
- 같은 문제를 다시 맞히면 최신 풀이로 갱신됩니다.
